# Kangwon – 블럭깨기

HTML과 JavaScript로 만드는 간단한 블럭깨기 게임입니다.
코딩과 GitHub 사용법을 배우기 위한 연습 프로젝트입니다.

## 실행 방법

`index.html` 파일을 브라우저(Chrome 등)로 열면 바로 실행됩니다. 별도 설치는 필요 없습니다.

## 조작법

- `←` `→` `↑` `↓` 방향키: 패들 이동 (상하좌우)
- 금색 블럭을 깨면 공이 1~10개 복제됩니다.
- 블럭을 깰 때마다 점수를 얻습니다. 클리어는 없고, 최고 점수를 노리는 방식입니다.
- 10초마다 블럭이 한 줄씩 내려옵니다. 블럭이 빨간 점선(위험선)에 닿거나 공이 모두 사라지면 게임 오버입니다.
- 게임이 끝나면 `스페이스`로 다시 시작합니다.
