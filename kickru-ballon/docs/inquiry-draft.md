# 운영팀 문의문 초안

보내기 전에 약관/연락처 페이지에서 문의 주소를 확인하세요. 발송은 직접 합니다.

---

제목: 개인 기기에서의 자동 플레이 스크립트 사용 가능 여부 문의

안녕하세요. 벤치에서 발롱까지를 즐기는 이용자입니다.

개인 학습 목적으로, 제 브라우저에서 게임 화면을 조작하는 스크립트(자동 플레이)를 만들어 보려 합니다.
이용약관 제3조에 "조작 기록의 반복 등록, 과도한 자동 요청"을 허용하지 않는다는 문구가 있어 먼저 문의드립니다.

1. 제 기기 안에서만 동작하고 서버로 별도 요청을 보내지 않는 자동 플레이가 허용되는지 알고 싶습니다.
2. 허용된다면, 자동으로 만든 커리어가 랭킹에 등록되지 않도록 할 수 있는 설정이 있는지 알고 싶습니다.
3. 허용 범위(속도, 동시 실행 수, 하루 횟수 등)에 제한이 있다면 알려 주세요.

답변을 받기 전에는 자동 플레이를 실행하지 않겠습니다. 감사합니다.
